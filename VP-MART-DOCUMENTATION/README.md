# VP Mart – Enterprise Multi-Vendor E-Commerce Marketplace
## Comprehensive Technical Documentation Package

Welcome to the technical documentation package for **VP Mart**, a modern full-stack multi-vendor e-commerce platform built with React 19, Node.js, Express, MongoDB Atlas, and Socket.IO.

---

## 1. Executive Summary

VP Mart is designed as a distributed, multi-role e-commerce ecosystem connecting independent vendors, end-consumer buyers, local delivery agents, and platform administrators. Built on clean architecture principles, VP Mart addresses common e-commerce challenges such as double-spend avoidance during checkout, real-time logistics tracking, strict role-based access control, and low-latency catalog search.

### Core Architecture Highlights
- **Client Application**: Single Page Application (SPA) built with React 19, Vite 8, React Router 7, and React-Bootstrap with a custom motion-enhanced design system.
- **Backend API**: Modular REST API with Express 5 on Node.js 22+, featuring rate limiting, CSRF protection, double-submit cookie authentication, and transaction safety.
- **Database Layer**: MongoDB Atlas with 27 specialized collections, unique and compound indexes, atomic transaction boundaries, and schema enforcement via Mongoose.
- **Real-Time Layer**: WebSocket server powered by Socket.IO for dispatch orders, real-time push notifications, and agent tracking.
- **Payment Gateway**: Seamless integration supporting Razorpay checkout with HMAC-SHA256 signature verification, paired with an interactive simulated fallback sandbox.

## 3. Technology Stack Reference

### Frontend Stack
- **Framework & Runtime**: React 19.3, Vite 8.3
- **Routing**: React Router 7.18
- **UI Framework & Styling**: Bootstrap 5.3, React-Bootstrap 2.10, Custom CSS Design System (`storefront.css`, `main.css`, `razorpay.css`)
- **Icons**: React Icons (Feather Icons `react-icons/fi`)
- **HTTP Client**: Axios 1.20 with automatic CSRF token refresh interceptors
- **Real-Time Client**: Socket.IO Client 4.8
- **Testing**: Vitest 5.0, Testing Library (React, Jest-DOM, User-Event)

### Backend Stack
- **Runtime**: Node.js >= 22.12 LTS
- **Web Framework**: Express 5.3
- **Database & ODM**: MongoDB Atlas, Mongoose 9.11
- **Real-Time Engine**: Socket.IO 4.8
- **Security & Cryptography**: Helmet 8.3, CORS 2.8, Cookie-Parser 1.4, BCrypt 6.0, JWT (jsonwebtoken 9.0)
- **Validation**: Zod 4.6 (Strict schema evaluation)
- **Rate Limiting**: Express-Rate-Limit 8.7
- **Logging**: Pino 10.4, Pino-HTTP 11.0
- **Storage**: Sharp 0.35, Multer 2.5, AWS SDK S3 Client 3.1156
- **PDF Generation**: PDFKit 0.20 (Invoicing)
- **Payments**: Razorpay 2.9 (Official SDK & Simulation Engine)

## 5. Quick Start Instructions (Local Development)

### Prerequisites
- Node.js >= 22.12.0
- Access to MongoDB (local replica set or MongoDB Atlas connection string)
- Redis (optional accelerator; system automatically falls back to MongoDB when unavailable)

### 1. Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your MongoDB Atlas connection string and secrets
npm run seed:catalog    # Populates initial categories, brands, and products
npm run seed:admin      # Creates the initial platform administrator account
npm run dev             # Starts the backend on http://localhost:5000
```

### 2. Frontend Setup
```bash
cd frontend
npm install
cp .env.example .env
npm run dev             # Starts the Vite dev server on http://localhost:5173
```
Visit `http://localhost:5173` to explore the marketplace.
